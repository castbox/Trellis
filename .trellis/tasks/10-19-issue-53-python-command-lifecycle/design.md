# Design

Extract the existing init resolver into a dependency-light CLI utility, preserving its public init export where required. Keep configurator rendering backed by the selected command. Public operation entry points resolve once before relevant work; direct collection and postvalidation consumers must also be safe when called without init, without introducing old-task parser/session prerequisites. A shared shell-free invocation helper represents interpreter executable plus prefix args, including py -3; actual spawn consumers use it. Do not persist machine paths.

Regression architecture: build the CLI first; standalone Node driver is implementation-independent so it can test baseline 7bcbeaad31380e7a29c97898cb947c6120a61775 and candidate each with their own init/update same version. On Windows use actual copied Python executable/runtime or real launcher in isolated PATH, retaining Node/Git/Bash/system tools without exposing alternate Python. Record identities and reject invalid visibility. Run Windows scenarios and Unix python3 target cases in CI plus comparison mode with explicit baseline assertions. Preserve raw logs and JSON summary via Actions artifacts, keep matrix fail-fast false. Environment failure is distinct from expected baseline defect.

Release via existing fork attachment-only contract: bump CLI/Core together to next unused 0.7.0-castbox.5, pack exact pair, inspect dependency, isolate install, validate before tagging reviewed main. Attach checksums and source/run identity record, then download and reverify installed bytes. Never publish npm or alter upstream workflow guard.
